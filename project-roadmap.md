# Project Roadmap

## Vision

Build a reusable toolkit that measures, analyzes, visualizes, and improves CI/CD pipelines for mixed Spring Boot, Gradle multi-module, and FastAPI backend repositories.

## Milestones

### M0 — Repository and delivery foundation

- Establish Issue-first work tracking, Git Flow policy, CI verification, and semantic release automation.

### M1 — Evidence and execution core

- Implement the versioned unified evidence model, reliable command runner, raw artifact preservation, and JUnit/pytest collectors.

### M2 — Pipeline analysis

- Add Gradle dependency analysis, affected testing, GitHub Actions DAG reconstruction, and critical path computation.

### M3 — Comparison and reporting

- Add repeated benchmark runs, baseline comparison, regression detection, deterministic charts, Markdown/HTML reports, and Job Summary output.

### M4 — Consumer adoption

- Integrate with OnMaru-backend without copying consumer source or tests, then validate the reusable workflow on representative CI runs.
