## Acceptance Criteria

- [ ] Shell interpolation is not used; executable and arguments are separated.
- [ ] Timeout terminates the complete process tree and records the reason.
- [ ] stdout/stderr are separately preserved as redacted artifacts.
- [ ] Retryable and non-retryable failures are distinguished.
- [ ] Non-zero exit, timeout, signals, partial output, and secret redaction are tested.
