## Acceptance Criteria

- [ ] Environment, runner, suite, config, cache, fixture, and dependency mode are compared.
- [ ] Warmup, repetition, and minimum-valid-run policy is configurable.
- [ ] Median, p95 when sufficient, sample counts, deltas, and resource changes are reported.
- [ ] No baseline, mismatched conditions, missing artifacts, and insufficient runs are inconclusive.
- [ ] Thresholds combine relative percentage, absolute delta, and minimum samples.
- [ ] Result references every contributing BenchmarkRun and artifact.
