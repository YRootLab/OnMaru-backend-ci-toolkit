## Objective

Add a typed, versioned and fail-closed release-trend manifest reader.

## Scope

New `pipeline_toolkit.trend` model/parser/discovery modules and fixtures only.

## Acceptance Criteria

- Immutable tag, commit SHA, image digest, run conditions, metric samples, and artifact provenance parse deterministically.
- Incomplete identity, unsafe URI, duplicate metric and non-finite sample fail closed.
- Failed or incomplete runs can be displayed but contribute no performance samples.

## Verification

`PYTHONPATH=src python3 -m pytest -q tests/test_trend_manifest.py`
